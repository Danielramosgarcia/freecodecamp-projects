# Palindrome Checker

Aplicação que verifica se uma palavra ou frase é um palíndromo, ignorando pontuação, espaços e capitalização.

## Funcionalidades

- Verifica se uma palavra ou frase é um palíndromo
- Remove caracteres não alfanuméricos antes da verificação
- Ignora espaços, pontuação e diferença entre maiúsculas e minúsculas
- Exibe alerta ao submeter campo vazio
- Exibe resultado diretamente na página sem recarregar

## Tecnologias

- HTML
- CSS
- JavaScript
