# Markdown to HTML Converter

Aplicação que converte texto em Markdown para HTML em tempo real, com pré-visualização instantânea.

## Funcionalidades

- Converte headings de nível 1, 2 e 3 (h1, h2, h3)
- Converte texto em negrito usando ** ou __
- Converte texto em itálico usando * ou _
- Converte sintaxe de imagem para elementos <img>
- Converte sintaxe de link para elementos <a>
- Converte citações para elementos <blockquote>
- Exibe o código HTML bruto em tempo real
- Renderiza o HTML com pré-visualização visual
- Atualização instantânea a cada caractere digitado


## Tecnologias

- HTML
- CSS
- JavaScript
- Expressões Regulares (Regex)
