# Spam Filter

Aplicação que detecta mensagens de spam usando expressões regulares para identificar padrões suspeitos.

## Funcionalidades

- Verifica se uma mensagem contém padrões de spam
- Detecta variações de escrita como substituição de letras por números (Leet Speak)
- Utiliza uma lista de expressões regulares para identificar múltiplos padrões suspeitos
- Ignora diferença entre maiúsculas e minúsculas na verificação
- Exibe alerta ao submeter campo vazio
- Exibe resultado diretamente na página sem recarregar

## Tecnologias

- CSS
