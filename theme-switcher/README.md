# Theme Switcher

Aplicação de troca de temas com menu dropdown acessível e feedback visual usando aria-live.

## Funcionalidades

- Alterna entre quatro temas: Light, Dark, Ocean e Nord
- Menu dropdown acessível com atributos ARIA (aria-haspopup, aria-expanded, aria-controls)
- Exibe mensagem personalizada ao trocar de tema
- Transição suave de cores ao mudar o tema
- Remove tema anterior automaticamente antes de aplicar o novo
- Acessível para leitores de tela com aria-live e role="menu"


## Tecnologias

- HTML
- CSS
- JavaScript
