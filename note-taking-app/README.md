# Note Taking App

Aplicação de notas editáveis com feedback de status e acessibilidade usando aria-live.

## Funcionalidades

- Permite editar notas diretamente na página usando contenteditable
- Exibe mensagem de status "Note saved successfully!" ao salvar
- Limpa mensagem de status quando o usuário volta a editar
- Detecta automaticamente se houve alterações na nota
- Acessível para leitores de tela com aria-label e aria-live


## Tecnologias

- HTML
- CSS
- JavaScript
