# FreeCodeCamp Projects

Projetos desenvolvidos durante o curso de JavaScript do FreeCodeCamp.

## Projetos

- [Football Team Cards](./football-team-cards/) - Aplicação de cards de time de futebol com filtro por posição.
- [Accessible Planets Tablist](./accessible-planets-tablist/) - Aplicação de abas com informações sobre planetas, focada em acessibilidade.
- [Note Taking App](./note-taking-app/) - Aplicação de notas editáveis com feedback de status e acessibilidade usando aria-live.
- [Theme Switcher](./theme-switcher/) - Aplicação de troca de temas com menu dropdown acessível e feedback visual usando aria-live.
